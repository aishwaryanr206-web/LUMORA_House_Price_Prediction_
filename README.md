# 🏡 LUMORA — House Price Prediction

An intelligent real estate valuation and insights platform powered by Machine Learning.

## 📌 About the Project

LUMORA predicts house prices using machine learning and property features. The project provides a web interface where users can enter property details and obtain an estimated price.

## ✨ Features

- House price prediction using Linear Regression
- Property data preprocessing and feature engineering
- Interactive frontend built with React and Vite
- Python backend for prediction
- Trained machine learning model

## 🛠️ Tech Stack

- **Frontend:** React, Vite, JavaScript, CSS
- **Backend:** Python, Flask
- **Machine Learning:** Scikit-learn, Pandas, NumPy
- **Model Storage:** Joblib

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/aishwaryanr206-web/LUMORA_House_Price_Prediction_.git
cd LUMORA_House_Price_Prediction_
```

### 2. Set up the Python backend

```bash
cd LUMORA_House_Price_Prediction/backend
pip install -r requirements.txt
python app.py
```

### 3. Start the frontend

Open a new terminal:

```bash
cd LUMORA_House_Price_Prediction_/LUMORA_House_Price_Prediction/frontend
npm install
npm run dev
```

Follow the local URL shown by Vite.
